About the Project

This project is a front-end clone of the Amazon website, developed as part of my Industrial Training (IT) project. It was created to practise and improve my web development skills by recreating the layout and design of a popular e-commerce platform.

The project replicates selected elements of Amazon's user interface, providing an opportunity to explore how e-commerce websites organise and display their content.

✨ Features

- Amazon-inspired website layout and design
- Product display sections
- Navigation and search interface
- Product images and visual elements

🛠️ Technologies Used

- HTML
- CSS
- JavaScript

🚀 Getting Started

To view the project locally:

1. Clone this repository:
   git clone (https://github.com/Feyi07/amazonclonesite)
2. Open the project folder.
3. Open the "home.html" file in your web browser.

Project Purpose

The goal of this project was to gain practical experience in front-end web development, understand the structure of an e-commerce interface, and apply web technologies to a hands-on project.

📚 What I Learned

Through this project, I gained practical experience working with website structure, page layout, visual elements, and front-end development.
